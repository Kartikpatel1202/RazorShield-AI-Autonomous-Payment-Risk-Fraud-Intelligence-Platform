# ml/

Fraud risk modelling package. **Empty by design in Phase 1.**

| Directory    | Responsibility (later phases)                                  |
| ------------ | -------------------------------------------------------------- |
| `data/`      | Dataset loading and train/test splits                            |
| `features/`  | Feature engineering for transaction risk                         |
| `models/`    | Model definitions and serialised artefacts                       |
| `training/`  | Training entrypoints and evaluation reports                      |
| `inference/` | Scoring interface consumed by the backend risk service           |

No model, dataset, feature or anomaly-detection code exists yet.
