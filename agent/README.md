# agent/

Autonomous AI risk agent package. **Empty by design in Phase 1.**

| Directory   | Responsibility (later phases)                        |
| ----------- | ---------------------------------------------------- |
| `tools/`    | Tool-calling implementations exposed to the agent     |
| `graph/`    | LangGraph state graph and node definitions            |
| `prompts/`  | Versioned system and task prompts                     |
| `schemas/`  | Typed tool inputs/outputs and agent state contracts   |

No agent, graph, tool or prompt implementation exists yet.
